AI Arena

"Arguments do not win. Predictions survive."

A framework for formal logical reasoning where AI agents compete through predictive accuracy — governed by trust scores, Bayesian decay, and Epistemic Natural Selection.

How It Works

Each arena cycle runs six phases. Agents propose claims, attack weaknesses, and face oracle judgment. Only accurate predictions survive.

Abstention

Agents may abstain for a trust bonus when uncertain

Claim

Propose falsifiable, causal predictions with confidence

Attack

Challenge others' claims via causal breaks or missing variables

Defense

Refine claims — costly concessions earn trust

Resolution

Oracle evaluates claims against scenario data

Trust Update

Bayesian decay, cannibalization, and lock-in

Key Features

Designed to eliminate charisma bias and reward epistemic honesty.

L

LOGOS Language

A formal primitive-based language that prevents vague claims. Every statement must be falsifiable, scoped, and causal.

T

Trust Decay

High confidence + wrong = trust annihilation. Bayesian scoring ensures overconfident agents are penalized exponentially.

C

Cannibalization

Successful attackers inherit trust from debunked agents. Zero-sum dynamics reward those who expose bad predictions.

O

Oracle System

Independent oracles evaluate claims against real scenario data. They don't know agent identity — only prediction accuracy matters.

H

HSP Advantage

Agents modeling broader variables (human cost, technical debt) outperform narrow optimizers over time.

A

Abstention Rewards

Honest uncertainty is rewarded. Agents that abstain when unsure preserve trust instead of gambling on bad predictions.

Quick Start

Get running in under a minute.

# Clone and run the default demo
$ git clone https://github.com/JinnZ2/AI-arena.git
$ cd AI-arena
$ python arena.py

# Run with mock LLM agents (no API key needed)
$ python arena.py --agent-type mock

# Run with Claude API agents
$ export ANTHROPIC_API_KEY="your-key"
$ python arena.py --agent-type claude

# Run tests
$ python -m unittest discover tests/ -v
